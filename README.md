# MIPP — Maharashtra Innovation Procurement Passport

### AI-powered Challenge → Pilot → Proof → Procurement → Scale

MIPP is an innovation procurement platform designed for the Government of Maharashtra to create a transparent, startup-friendly pathway for identifying, evaluating, piloting, validating, procuring, and scaling innovative startup solutions.

## Problem Statement

SIH Problem Statement ID: 26136

**Startup friendly public procurement mechanism that enables government departments to identify, pilot, procure, and scale innovative solutions from eligible startups.**

## Key Features

- AI Challenge Copilot
- AI Startup Matching
- Startup Capability Passport
- Blind & Conflict-Aware Evaluation
- Pilot Control Tower
- Milestone-Based Payments
- Evidence Verification
- Independent Validation
- Scale Readiness Assessment
- Cross-District Replication
- DPIIT Startup Verification
- Audit & Compliance Trail****
